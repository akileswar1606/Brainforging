# BrainForging

Learn. Practise. Build.

- `index.html` is the whole website.
- `courses/beckhoff-twincat-3/` holds the course: `course.json` plus `module-1.json` to `module-8.json`.
- `database/supabase-all.sql` is run once in the Supabase SQL Editor. It is not used by the website.

Open the site from GitHub Pages, not by double-clicking `index.html`, because browsers block reading the course files from your computer.
